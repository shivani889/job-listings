# Job Listing Application

A responsive job listing application built with React.js, Tailwind CSS, and JSON Server.

## Features

- Search and view job listings
- Add new job listings
- Edit existing job listings
- Delete job listings
- CRUD operations
- Responsive user interface
- Reusable React components
- Client-side routing
- Form handling and validation
- Local API integration using JSON Server
- Toast notifications

## Tech Stack

- React.js
- JavaScript
- Tailwind CSS
- Vite
- React Router
- JSON Server
- React Icons
- React Toastify

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shivani889/job-listing.git

**2. Navigate to the project folder**
cd job-listing

**3. Install dependencies**
npm install

**4. Start JSON Server**
npm run server

**5. Start the React development server**
npm run dev

**Project Purpose**
This project was developed as a hands-on React.js project to practice component-based development, CRUD operations, routing, form handling, API integration, and responsive UI development.
